## 🧭 Sobre este repo

Portafolio de una sola página, escrito a mano en HTML/CSS/JS puro —
**cero frameworks, cero build step**. Lo que ves en producción es
exactamente el archivo que está en este repo. El CV descargable va
incrustado en el propio HTML, así que el sitio no depende de nada
externo para funcionar.

```
📁 portafolio
 ├── index.html   → todo el sitio (HTML + CSS + JS en un solo archivo)
 └── README.md    → esto que estás leyendo
```

## 🔩 Lo que muestra el sitio

| Proyecto | Qué hace |
|---|---|
| **Auditor de Código y Archivos** | Análisis estático de seguridad (SAST) y hashes de integridad, en Python/Tkinter |
| **Network Auditor Pro** | Suite de auditoría de redes con anti-spoofing y evasión de AP Isolation |
| **Sistema Contable ERP** | ERP multi-cliente con módulo de Auditoría Financiera y normativa SENIAT |
| **Argame Paseo Mirandino** | App de gestión para mi negocio de alquiler de consolas, con IA integrada |

## 🚀 Correrlo en local

No hay dependencias ni instalación — es un solo archivo:

```bash
git clone https://github.com/Aalejandro996/portafolio.git
cd portafolio
open index.html   # o doble clic en el archivo
```
